# Changelog

The changes of mergeable-rs are published with every release on the
[GitHub releases page](https://github.com/Ch4s3r/mergeable-rs/releases). The release notes are generated from the
conventional commits, see [Releases and versioning](./releases.md).

The changelog of the original Node.js implementation, whose behaviour mergeable-rs reproduces, is kept on the
[Original project history](./original-project-history.md) page.
