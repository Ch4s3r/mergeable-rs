# Supply chain

Every release publishes, next to the [container image](./container-image.md), a software bill of materials (SBOM) and
signed attestations, so you can check what is in an image and that it was built by this repository's release workflow.

## What is published

| Artifact | Where |
|---|---|
| CycloneDX SBOM (`mergeable-rs-<version>.cdx.json`) | asset of the [GitHub release](https://github.com/Ch4s3r/mergeable-rs/releases) `v<version>` |
| SPDX SBOM (`mergeable-rs-<version>.spdx.json`) | asset of the GitHub release `v<version>` |
| Build provenance attestation ([SLSA](https://slsa.dev) v1, signed with [Sigstore](https://www.sigstore.dev)) | GitHub attestations API and the registry, next to the image digest |
| SBOM attestation (the CycloneDX SBOM, signed with Sigstore) | GitHub attestations API and the registry, next to the image digest |
| Buildpacks SBOM | embedded in a layer of the image |

The SBOMs are generated by [syft](https://github.com/anchore/syft) from the published image (by digest). They list
the Ubuntu packages of the Paketo run image, the Rust crates of `Cargo.lock` (read from the SBOM the buildpacks embed),
tini and the Go modules of the buildpacks launcher. The release notes name the image digest.

## Download the SBOMs

```bash
gh release download v<version> -R Ch4s3r/mergeable-rs -p '*.json'
```

The SBOM the buildpacks embed in the image (CycloneDX and Syft for the crates, CycloneDX, SPDX and Syft for the
launcher) is fetched with [pack](https://buildpacks.io/docs/for-platform-operators/how-to/integrate-ci/pack/):

```bash
pack sbom download ghcr.io/ch4s3r/mergeable-rs:<version> --remote --output-dir sbom
```

## Verify the attestations

With the [GitHub CLI](https://cli.github.com):

```bash
gh attestation verify oci://ghcr.io/ch4s3r/mergeable-rs:<version> --owner Ch4s3r
gh attestation verify oci://ghcr.io/ch4s3r/mergeable-rs:<version> --owner Ch4s3r \
  --predicate-type https://cyclonedx.org/bom
```

The first command verifies the build provenance: the image digest was built by `.github/workflows/release.yml` of
`Ch4s3r/mergeable-rs`. The second verifies the signed SBOM. Add `--format json` to print the verified attestations,
for example to extract the SBOM with `jq '.[0].verificationResult.statement.predicate'`. Verify by tag only for a
quick check; in a deployment pin the image by digest (`ghcr.io/ch4s3r/mergeable-rs@sha256:...`) and verify that.

Releases before the first one with this feature have no attestations or SBOM assets; only their embedded buildpacks
SBOM is available.
