# Support

Found a bug? Have a question?

- Create an [issue](https://github.com/Ch4s3r/mergeable-rs/issues/new) in the mergeable-rs repository.
- Questions about the behaviour of a rule that also apply to the original implementation can be checked against the
  [original project](https://github.com/mergeability/mergeable) and its issues; mergeable-rs reproduces its webhook
  behaviour.
